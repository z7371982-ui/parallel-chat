# 并行对话

可通过 Git 仓库地址安装的 SillyTavern / TauriTavern 前端扩展。无需酒馆助手或单独服务端插件。

## 上传 GitHub

1. 创建一个 GitHub 仓库。
2. 将本目录内的 `manifest.json`、`index.js`、`runtime.js`、`README.md` 等文件上传到**仓库根目录**。不要再套一层文件夹。
3. 在酒馆的「扩展 → 安装扩展」中粘贴仓库地址，安装并按宿主提示刷新。

首次启用默认显示悬浮入口。到「扩展设置 → 并行对话」取消「显示悬浮窗」可隐藏，选择会随酒馆设置保存。隐藏入口不会停止正在生成的会话。也可以用这里的「打开并行面板」按钮临时打开面板；它不会改变显示开关。

默认显示的是悬浮入口，首次开启并行模式仍需点击面板里的开启按钮。

## 从酒馆助手脚本迁移

先等已有生成结束，停用旧的酒馆助手全局脚本，再安装扩展并刷新。旧脚本与扩展不要同时运行。若检测到旧脚本，扩展会提示迁移，保留已有会话。

## 更新

将新版文件提交到同一仓库，用户即可用宿主扩展管理器的更新功能拉取更新，随后在生成结束后刷新页面。没有启用静默自动更新。

## 功能与限制

- 保留最多三个页面内会话，支持选择角色的不同聊天记录。
- 切换显示时，已打开的会话继续走宿主原生生成流程。
- 后台完成角标、默认开启的提示音，面板设置可关闭声音。
- 关闭悬浮入口与退出并行模式是不同操作。
- 刷新、退出应用、系统回收或手机后台休眠均不保证继续生成。
- 副会话的全局设置临时生效，持久设置请在主页面修改。
- 0.3.9 脚本已获用户反馈可在手机 TT 使用。0.4.1 扩展迁移仍需实机确认；浏览器测试不能代替 TT 或 Termux 真机验证。

## 文件

`manifest.json` 是宿主识别扩展的清单，`index.js` 负责扩展设置与启动，`runtime.js` 是并行会话运行逻辑。仓库名可自行选择，无须修改固定路径。项目不包含 API 密钥或聊天数据。
